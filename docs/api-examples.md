# Getting Started | 快速开始

Snippai is an AI-powered snipping tool for capturing screen content and turning it into useful output.
  
Snippai 是一个 AI 驱动的截图工具，可将屏幕内容快速转化为可用信息。

## Download | 下载

Download the latest release from GitHub:  
从 GitHub 下载最新版本：  
[https://github.com/xyTom/snippai/releases](https://github.com/xyTom/snippai/releases)

## Install | 安装

- **Windows**: Download the installer and follow the setup wizard.  
  **Windows**：下载安装包并按向导完成安装。  
- **macOS / Linux**: Download the package that matches your system and install manually.  
  **macOS / Linux**：下载对应系统的安装包并手动安装。

## First Use | 首次使用

1. Launch Snippai.  
   启动 Snippai。  
2. Trigger screen capture with your configured shortcut.  
   使用你设置的快捷键进行截图。  
3. Select a region and choose an AI action (OCR, formula, table, translation, etc.).  
   选择截图区域并执行 AI 动作（OCR、公式、表格、翻译等）。  
4. Copy or export the generated result.  
   复制或导出生成结果。

## Typical Use Cases | 常见场景

- Capture textbook formulas and convert to LaTeX.  
  截取教材公式并转换为 LaTeX。  
- Extract text from screenshots for editing.  
  从截图中提取文本用于编辑。  
- Convert table screenshots into Markdown tables.  
  将表格截图转换为 Markdown 表格。  
- Translate foreign-language interface text instantly.  
  即时翻译外语界面内容。
